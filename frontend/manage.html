Gunakan akun server yang emailnya telah diverifikasi dan sudah diberi izin operator dari komputer server.

Belum memiliki izin? Daftar dan verifikasi akun melalui aplikasi, lalu berikan akses menggunakan perintah npm run server:manage -- grant-operator EMAIL pada komputer server.
