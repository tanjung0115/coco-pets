Privasi dan penghapusan data

Berlaku untuk trial lokal COCO Pets, 25 Oktober 2026. Belum merupakan layanan publik.

Data yang disimpan

Nama, email, kontak, foto, profil hewan, catatan perawatan, keranjang, riwayat pesanan dan booking disimpan pada perangkat. Jika akun server digunakan, data disimpan juga di server pilihan pengguna. Password server disimpan sebagai hash. Sesi login memakai token. Server menyimpan status verifikasi, token perangkat dan laporan perangkat.

Tujuan dan akses

Data digunakan untuk login, sinkronisasi dan fitur perawatan, pemesanan serta perangkat. Pengelola server dapat mengakses informasi pelanggan yang diperlukan untuk mengelola booking dan pesanan. Tidak ada layanan iklan atau analitik pihak ketiga yang ditambahkan. Email verifikasi/reset pada mode lokal berada di outbox privat pengelola; SMTP/webhook baru digunakan jika dikonfigurasi.

Simulasi

Perangkat dummy berlabel SIMULASI, bukan lokasi hewan nyata. Pembayaran manual memerlukan pemeriksaan pengelola, bukan konfirmasi bank otomatis. Data kesehatan bukan diagnosis medis.

Penghapusan dan penyimpanan

Akun server disimpan sampai pengguna menghapusnya atau pengelola mengakhiri trial. Untuk menghapus akun server, buka About me → Penyimpanan server → Hapus akun saya, masukkan password saat ini dan konfirmasi. Ini menghapus profil, hewan, pesanan, booking, perangkat dan sesi dari database aktif. Penghapusan tidak menarik kembali backup yang sudah diunduh, email outbox atau salinan cache pada perangkat lain. Cadangan dan outbox perlu dihapus terpisah oleh pengelola. Cache di perangkat lain perlu dihapus lewat pengaturan aplikasi/browser.

Akun lokal dan file backup tetap berada pada perangkat sampai dihapus pengguna. Sebelum menghapus penyimpanan aplikasi atau mencopot aplikasi, cadangkan data yang ingin dipertahankan. Gunakan ekspor backup pada About me jika diperlukan.

Keamanan dan pertanyaan

Server HTTP lokal hanya untuk Wi-Fi trial tepercaya. Hubungi pemilik komputer/server yang mengadakan trial untuk bantuan akses, penghapusan cadangan atau koreksi data. Kontak pengelola publik, alamat kebijakan HTTPS dan periode retensi operasional harus ditetapkan sebelum distribusi publik.
